## 🌓 De Kern: Licht & Donker

### **"Zo licht als je bent, zo donker ben jij ook"**

```
Iedereen heeft BEIDE:
  ☀️ Licht (goed, liefde, groei)
  🌑 Donker (schaduw, pijn, angst)

Sommigen:
  - Een klein beetje donker
  - Anderen heel erg donker

MAAR:
  → Het gaat erom WAT JE KIEST OM TE ZIJN
```

### **Wat Dit Betekent:**

**Niet dit:**
```
❌ "Ik ben slecht persoon omdat ik darkness heb"
❌ "Mijn schaduw = wie ik ben"
❌ "Ik moet mijn darkness verbergen"
```

**Maar dit:**
```
✅ "Ik HEB darkness, maar ik KIES licht"
✅ "Mijn schaduw maakt me menselijk"
✅ "Erkenning > Verbergen"
✅ "Keuze > Definitie"
```

## 🪄 Magie & Balans

### **"Alles heeft een kant, net als magie"**

```
Om iets te laten groeien → Sterft iets anders

Voorbeelden:
  🌱 Plant groeit → Zaad sterft
  🦋 Vlinder ontstaat → Rups sterft
  💡 Idee realiseert → Oude versie sterft
  👶 Kind groeit → Afhankelijkheid sterft
```

### **Law of Equivalent Exchange:**

```
Niets komt zonder prijs:
  - Groei = Loslaten
  - Creatie = Destructie
  - Leven = Dood
  - Licht = Schaduw

→ Geen oordeel, gewoon balans
→ Acceptatie van cyclus
```

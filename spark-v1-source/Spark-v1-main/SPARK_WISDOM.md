## 🧮 EMOTIE ALS CODE: Het Complete Systeem

### **Basis: De 4 B's**
```
Blij (Happy)      = 01
Boos (Angry)      = 10
Bang (Scared)     = 11
Bedroeft (Sad)    = 00

+ Intensity: 0.0 - 1.0 (scalar)
+ Duration: Hoe lang duurt de emotie?
+ Trigger: Wat veroorzaakte het?
```

### **SMART Framework (Rationeel)**
```
Specific:   Is de emotie specifiek gericht?
Measurable: Kun je de intensiteit meten?
Achievable: Is er een oplossing mogelijk?
Relevant:   Is de emotie relevant voor situatie?
Time-bound: Heeft het een tijdsframe?

→ Helpt AI om emotie te contextualiseren
```

### **BELIEVE (Overtuiging)**
```
Believe Score: 0.0 - 1.0

Hoe sterk geloof je in:
  - De realiteit van de situatie?
  - De mogelijkheid tot verandering?
  - Je eigen vermogen om te handelen?
  
→ Lage believe = Hulpeloosheid
→ Hoge believe = Empowerment
```

### **NEED (Behoefte)**
```
Welke basisbehoefte is geraakt?

Maslow's Hiërarchie:
  1. Fysiologisch (eten, slapen, veiligheid)
  2. Zekerheid (stabiliteit, structuur)
  3. Liefde (verbinding, belonging)
  4. Waardering (respect, erkenning)
  5. Zelfactualisatie (groei, potentieel)

→ Identificeer de need = Begrip van emotie
```

### **5W+H (Context)**
```
WHO:   Wie is betrokken? (jezelf, anderen)
WHAT:  Wat is er gebeurd? (gebeurtenis)
WHEN:  Wanneer gebeurde het? (tijd, tijdlijn)
WHERE: Waar gebeurde het? (locatie, omgeving)
WHY:   Waarom raakte dit je? (diepere reden)
HOW:   Hoe manifesteert de emotie? (gedrag)

→ Complete context = Empathische response mogelijk
```
